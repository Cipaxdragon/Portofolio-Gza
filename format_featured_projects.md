## 💻 PROYEK 3

- **Judul Proyek:** Prabowo Bot — Discord Multi-Feature Bot
- **Deskripsi Singkat:** Bot Discord multifungsi bertemakan absurd nasional "Pak Prabowo" yang dibangun dengan Discord.js v14. Dilengkapi dengan sistem ekonomi virtual, AI Chat (Gemini & GPT), kuis interaktif multi-jurusan, latihan coding, sistem mancing berbasis rarity, fitur waifu/companion, player music, dan integrasi OAuth Roblox. Seluruh fitur dirancang secara modular dengan arsitektur event-driven.
- **Repo Name:** cipaxdragon/Bot_Discord
- **Repo URL:** https://github.com/cipaxdragon/Bot_Discord
- **Live URL:** https://discord.com/oauth2/authorize?client_id=1493929122190196856&permissions=8&scope=bot%20applications.commands
- **Bahasa Pemrograman Utama:** JavaScript
- **Teknologi yang Dipakai:** Node.js, Discord.js v14, Google Gemini AI, OpenAI GPT, Express.js, @discordjs/voice, play-dl
- **Fitur-Fitur Unggulan:**
  1. **🎣 Sistem Mancing (Ekonomi):** Command `!mancing` dengan sistem rarity bertingkat (Common → Rare → Legendary), cooldown otomatis, dan reward uang virtual. Dilengkapi `!inventory`, `!stats`, `!topfisher`, dan `!shop`.
  2. **🤖 AI Multi-Model:** Integrasi tiga model AI secara bersamaan — `!ai` (Google Gemini), `!wo` (persona Prabowo Subianto), dan `!gpt` (Ollama model lokal).
  3. **📚 Kuis Kuliah Otomatis:** Sistem kuis hybrid (MC + Essay) berbagai jurusan (Sistem Informasi, Kimia, Politik, Manajemen) yang auto-spawn setiap 5 menit. Jawaban essay dievaluasi langsung oleh AI.
  4. **💻 Coding Challenge:** Command `!koding` menghasilkan soal coding (Multiple Choice, Fix Code, Complete Code) untuk 6 bahasa (JavaScript, Python, PHP, React JS, Laravel, Luau) dengan 3 tingkat kesulitan.
  5. **💖 Waifu / Companion System:** Sistem hubungan virtual lengkap dengan state dinamis (Affection, Trust, Mood, Bond, Loyalty, Rarity). Mendukung interaksi talk, gift, date, marry, dan event konflik acak.
  6. **🎵 Music Player:** Fitur join voice channel dan memutar musik dari YouTube lewat `!play` menggunakan library `play-dl` dan `@discordjs/voice`.
  7. **🎮 Roblox OAuth Integration:** Server Express.js internal untuk menangani OAuth callback dari Roblox, menghubungkan akun Discord user ke profil Roblox mereka secara aman.
  8. **⬆️ Sistem Leveling & Leaderboard:** Setiap pesan chat di server memberikan XP otomatis. Tersedia command `!rank` dan `!leaderboard` untuk melihat peringkat server.

## 💻 PROYEK 4

- **Judul Proyek:** SIDANUS — Sistem Pendaftaran Ujian Akademik (React SPA)
- **Deskripsi Singkat:** Aplikasi web Single Page Application (SPA) untuk mengelola seluruh proses pendaftaran dan penjadwalan ujian akademik skripsi (Sempro, Ujian Hasil, Munaqasyah) di Jurusan Sistem Informasi UIN Alauddin Makassar. Dibangun sebagai proyek mata kuliah APSI dengan pendekatan React modern, sistem state management berbasis Context API, dan simulasi database menggunakan localStorage.
- **Repo Name:** cipaxdragon/APSI_3_React
- **Repo URL:** https://github.com/cipaxdragon/APSI_3_React
- **Live URL:** 
- **Bahasa Pemrograman Utama:** JavaScript
- **Teknologi yang Dipakai:** React 19, React Router DOM v7, Vite, Tailwind CSS v3, jsPDF, Lucide React
- **Fitur-Fitur Unggulan:**
  1. **🔐 Multi-Role AuthGuard:** Sistem login dengan 4 peran terpisah (Mahasiswa, Admin, Kaprodi, Penguji), masing-masing diarahkan ke portal dan dashboard yang berbeda secara otomatis setelah login.
  2. **📋 Portal Mahasiswa:** Pendaftaran ujian dengan slot upload dokumen yang beradaptasi otomatis sesuai jenis ujian. Dilengkapi tracking status real-time dan sistem notifikasi dari Admin.
  3. **🛡️ Portal Admin:** Verifikasi berkas, penjadwalan ujian dengan fitur **Auto-Saran Jadwal** (mendeteksi jam, ruangan, dan penguji yang tersedia otomatis), serta manajemen penguji.
  4. **🏛️ Portal Kaprodi:** Kalender akademik interaktif, persetujuan/penolakan jadwal dengan catatan alasan, dan riwayat log persetujuan lengkap.
  5. **📋 Portal Penguji:** Dashboard jadwal menguji, input nilai & catatan revisi via modal pop-up, dan riwayat semua ujian yang pernah diselesaikan.
  6. **📄 Generator PDF Surat Keterangan Lulus:** Mahasiswa yang telah menyelesaikan Munaqasyah dapat mencetak SKL resmi langsung dari browser menggunakan library jsPDF.
  7. **🗄️ Simulasi Database Modular:** Seluruh data dikelola via `localStorage` menggunakan modul `sidanusDB.js` yang bersifat terpusat, sehingga state konsisten di semua halaman layaknya backend nyata.

  - Format: video
  - Caption: Alur lengkap pendaftaran ujian dari Mahasiswa hingga persetujuan Kaprodi di SIDANUS
